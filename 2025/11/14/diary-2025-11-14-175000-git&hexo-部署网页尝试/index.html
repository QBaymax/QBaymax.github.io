git&hexo-部署网页尝试

Created2025-11-14 17:50:00|Updated2026-11-17 12:44:18|日记
|Post Views:

今天首先是修改了 hexo 构建网页的基本流程，之前就是通过hexo d构建网页，每次执行时，github.io 这个项目文件就会通过 deploy 重新构建网页，但这种手动构建的方法还是不通用。因此今天就研究了通过 Github Actions 来构建的方案，他是根据监测仓库是否有变化，从而自动去构建网页，因此我们可以直接改仓库中的 _post 来方便的上传日记，而不需要再手动让他 deploy。而 github.io 构建网页有且只能有一个途径，或者deploy，或者Actions。

那为什么会改变我的工作流程呢，hexo d（部署命令）本身通常只上传生成的静态网站文件，也就是 public 中的文件，而这里没有post文件夹，也就导致我没法在使用github actions时手机编辑。而 git 命令用于管理博客的源代码，二者是分工明确的，因此我就需要转为通过git命令去上传源代码到仓库中，再通过 actions 编译文件，并生成网页。

为了可能日后切换回 hexo d 命令，因为他更方便去做一些大型的更改，所以仓库就分成两部分，主仓库 main 用于保存源代码，而分支 gh-pages 则用于保存 hexo d 上传的内容，这样我可以通过切换 github 的部署方式来切换我的工作流程。详细细节我会在文章中讨论。
